# 《虚线》Unity 互动 Demo：策划需求与验收清单

阅读依据：根目录《策划稿.md》、`场景建模文档`全部七份文档、五场交付的《使用说明》《验收记录》，以及 `交付/圣家堂/Data/SAG_runtime_interfaces.txt`。本清单记录应实现的体验及验证方法，不把 Blender 建模验收等同于 Unity 游戏验收。编写日期：2026-10-11。

运行环境已经准备完成：Unity Editor `6000.6.5f1`，安装在 `C:\Program Files\Unity\Hub\Editor\6000.6.5f1\Editor\Unity.exe`。`-version` 实测输出 `6000.6.5f1`，UnityEngine/UnityEditor 托管程序集、Mono C# 编译器、DotNetSdk/Roslyn、Windows Standalone Mono Player、Package Manager 与 Bee 构建程序均存在。安装使用已在 Unity Hub 下载完成的正式安装包，没有引入便携编辑器或重复 Editor 下载。项目编译与可执行构建验收以 `TestResults` 的实际日志为准。

## 本次交付边界

用户指定完整五建筑版本：比萨、帕特农、万神殿、科隆、圣家堂。工作室是序章与结局共用空间，终页在圣家堂中殿继续，均不另计主场景。策划中的四建筑删减方案不使用。

本次重点是能够实际操作、按步骤走通的 Unity Demo。背景动画、历史年代快放、过场动画交由用户后续制作；以即时状态切换、门触发和文字承接留出接口即可。画作使用本地预生成结果，演示按确定输入和候选推进，无需覆盖自由输入的全部解析、任意提示词、在线 AI 或异常绘画情况。预生成结果仍应对应本页的结构与操作，不能把所有关卡变成同一按钮播放图片。

原策划有多解、失败与分支；本次必需完成一条忠实的完整成功路线。原稿分支列为拓展验收，不因未实现全部任意输入判定而阻挡演示交付。序章、终页、玻璃补桥构成故事回环，应有可操作承接；角色身体、外婆模型和完整配音不在实现前提内。

下列方框是后续人工复验用的逐项清单，不是当前缺陷数量。已执行的构建、自动操作和独立截图检查以文末“实际验证记录”与状态表为准；未经实际键鼠操作的条目不预先勾选。

## 共用交互与画板

- [ ] 玩家可在场景内移动和观察，具有明确的交互提示；进入菜单、书页时不误触世界交互。
- [ ] 任意位置可打开速写本；每页提供对应笔刷、批注与预生成画，不出现自由文字提示词输入框。
- [ ] 核心动作保留“选择笔刷／描画或擦除 → 收笔 → 查看预生成结果 → 取景 → 落笔”的体验；演示可吸附到既定笔画和结果。
- [ ] 取景只在本页固定点成立，`F` 举页、左键落笔；对齐有明确反馈。若使用辅助对齐，仍让玩家执行取景与落笔。
- [ ] 对齐成功阈值严格为角误差 `< 3°`，而非 `<= 3°`。误差 `< 1°` 新补浅一级，`1° <= 误差 < 3°` 浅两级；不能影响结构几何。
- [ ] 序章单张；普通建筑页三张；科隆为同结构的蜡笔 `0% / 30% / 60%`；终页只有一份结果且不展示硫酸纸和参数数字。
- [ ] 一轮最多五笔；帕特农八柱完整路线须分两轮；门框在门显影后从页上消失，不计核心笔画和结构判定。
- [ ] 万神殿排水孔、圣家堂链、圣家堂擦镜子这三类收笔即时生效；它们不要求再次举页。
- [ ] 本页所有必需操作完成后才合页/开放出口；普通一次落笔可只完成部分，不重置先前完成构件。
- [ ] 整体保持 HB 铅笔世界与较浅的新补材质差异；幽灵线不挡路、不承重。
- [ ] Demo 不依赖网络即可从序章走到结局；预生成图缺失时有有效本地几何/图像兜底。

### 场景一：比萨斜塔

- [ ] 初始只有三层实体塔身、向南倾 `5.5°`；四层续建柱廊与独立钟室为空缺虚线，外婆原虚线继续顺斜轴向上。
- [ ] 能读到两种批注：“歪了不要紧”与“我画错了。往回修一点”。
- [ ] 使用轴线笔描出从第三层檐口向上的回弯，候选显示起弯层、每层回弯、钟室倾角。
- [ ] 演示默认可选 `k=5, δ=1.4°`，钟室绝对倾角约 `0.1°`；模型实际回弯，不能只把整塔旋转。
- [ ] 到西侧铜钉举页/落笔，新四层与钟室出现，七口钟挂正；钟室可有敲钟互动与成功文字。
- [ ] 检查默认结构：`δ > 0`、每层相对下层延长轴错位 `<= 0.4m`、钟室倾斜 `<= 2°`。
- [ ] 合页后在塔底指定西南盲拱画门框，多立克门楣显影，推门进入帕特农。
- [ ] 转场文本接口：447 BC、432 BC、1687、1933、2001、2014。

结构口径：`theta_i = 5.5° - max(0, i-k+1)*δ`；新层顶点沿该层轴线连接，柱廊竖高 6m、钟室竖高 7.5m；错位用 `h_i*abs(tan(theta_i)-tan(theta_(i-1)))`，不能用两层中心的绝对距离替代。

### 场景二：帕特农北柱廊

- [ ] 北廊 17 槽：西端 5 根实体、中缺 8 根、东端 4 根实体；16 个旧鼓与 9 个额枋有稳定身份。
- [ ] 在世界中操作旧鼓，将其推滚/移到待补柱位；接入方式须让玩家实际完成“用地上的”。
- [ ] 一笔一柱，先画 06–10 五柱，查看候选吃鼓读数，再固定取景落笔。
- [ ] 第二轮画 11–13 三柱，选结果并再落笔；第二轮不让第一轮柱、归位梁或旧鼓状态消失。
- [ ] 柱位节奏参考两端旧柱；演示落点对应间距约 `4.3m`，容差 `±0.9m`；柱竖直度 `<= 3°`。
- [ ] 旧鼓被纳入柱身，旧石深色、新石浅白；同一旧鼓不同时留在地上和柱内。
- [ ] 一跨两端柱完成后原额枋归位；四个堵路跨 06–07、07–08、08–09、09–10 打开，地面碰撞同时解除。
- [ ] 未用旧鼓会阻止合页；晚投入鼓可进入已立柱脚 `0.5m` 范围并替换局部新石，实际测点采用接触点水平投影，避免鼓半径造成死锁。
- [ ] 八柱完整路线使全部旧鼓归位，出现檐壁奖励；到东方前廊，在内殿东墙旁画青铜双门并进入万神殿。
- [ ] 门楣受控铭文准确为 `M·AGRIPPA·L·F·COS·TERTIVM·FECIT`；转场文本接口：27 BC、80、125。

拓展原稿分支分开记录 `route_open/page_closed/restoration_complete`：五柱开四跨且石头全用可合页候选，但不等同于八柱完整修复；集中两柱各八鼓时“全新柱六根”是奖励等级提示，不用于卡住成功演示。

### 场景三：万神殿

- [ ] 初始黑顶、浅水，圆厅内径与理论顶高均 `43.3m`；极淡穹顶弧与页上墨下压痕给出擦口依据。
- [ ] 第一阶段：橡皮擦穹顶顶点的眼洞、太阳印章选正午；从三张 `6.4 / 7.8 / 9.6m` 中演示选择 `7.8m`。
- [ ] 门槛内侧固定点由同心水纹和“站在门槛里”提示；举页、淡弧对齐并落笔。
- [ ] 真孔与压力环出现，状态为落雨和积水，页仍开；不能首次落笔直接晴天或开出口。
- [ ] 第二阶段：用重复排水孔笔在地面线画小圆，收笔即更新孔与水位；演示四孔，孔数不是另加的结构规则。
- [ ] 排水过程中水/雨仍可辨认；达到干地面后停雨，正午光覆盖门槛固定 `×`，140 格藻井保持五圈×28格的层次。
- [ ] 合页条件：直径 `6–9m`、偏心 `<=1.5m`、太阳正午 `±20分钟`、排干且光到门槛；水下的光或独立永远照准×的聚光灯不能提前过关。
- [ ] 使用序章半蜡笔画补齐下一页/半门框，半石半蜡笔尖拱门显影，交互进入科隆。
- [ ] 保留故事：“下雨了，我把顶上关了。等天晴的人来擦”；铭文批注指向“哈德良重建，仍写阿格里帕”。
- [ ] 转场文本接口：1248、1473、1814 达姆施塔特、巴黎、1842、1880。

### 场景四：科隆大教堂

- [ ] 西面固定视角：完整北塔在左 `157m`、南墩在右 `56m`、墩顶虚线木起重机、地面花饰残片。
- [ ] 已持有的半画压入右页为底图，拼口相同；翻背可读“禾禾六岁。她说南塔没盖完，她来画。”
- [ ] 照北塔描南塔轮廓，三条参考线 `56/88/108m` 有勾选反馈；再用橡皮在塔尖内擦孔，演示 `52%` 镂空率。
- [ ] 三候选结构与孔形相同，只分别显示蜡笔 `0/30/60%`，选中值实际影响新南塔外观；覆盖蜡笔开关有对应效果。
- [ ] 在广场固定点举页/落笔，南塔补到 157m；真实开孔可透视，起重机移到边缘，页合。
- [ ] 标准规则：三参考线镜像误差各 `<=2m`，镂空率 `45%–85%`（分母为投影封闭 SPIRE 区域，不含顶部 FINIAL）。
- [ ] 可选吊索路线：从吊臂连接地面唯一残片，原物移到塔尖，镂空自动满足、轮廓容差 `<=4m`；不得要求必须先捡蜡笔头才通关。
- [ ] 地面门框第一次画在广场地上，青铜植物门向下开启，跳入/交互进入圣家堂模型室，无无限掉落。
- [ ] 年份接口：1882、1926、1936、2025；不引入 2026 年建造现状。

### 场景五：圣家堂模型室 → 中殿

- [ ] 地面始终向下；4钩、3跨、5片、灰镜、工作台和老照片存在，页上只留左半挂钩且线抖。
- [ ] 先用页上橡皮擦镜面灰，收笔即时更新擦除区域，中央清净；外围灰不被错误一键消除。
- [ ] 逐跨使用链子笔接 H1–H2、H2–H3、H3–H4，收笔即时挂链；右侧空白挂钩因端点吸附而补显。
- [ ] 链只读取端点与弧长，并沉降；候选来自相同链长下的碎片补全/重量，页角显示实际求解净高，不能伪造 41/44/47 读数。
- [ ] 每跨捕获至少一块本跨碎片；F1/F2/F3固定属A/B/C，F4只属A/B、F5只属B/C，第一次捕获后唯一归属。
- [ ] 镜中相应一跨拱随链出现；选候选校齐三跨，相邻拱轴高差 `<=1.5m`。
- [ ] 三跨与中央清灰完成后，镜中心固定点举倒页/对齐/落笔进入中殿；使用即时切换即可，世界与输入轴不翻转。
- [ ] 中殿树柱、分叉、新拱实际出现，东侧蓝绿、西侧红橙可辨认。
- [ ] 模型单位：捕获半径 `0.5模型m`；高差 `0.15模型m = 1.5中殿m`；不能把这两个阈值混用。

映射 `P=(10(x+1.2),10y,10(6-z))`；RoomRoot 与 NaveRoot 独立，源文件 `(32,0,0)` 是制作偏移，不能当玩家要走的连接通道。镜中展示从同一结构驱动，真实镜面本身不会把链自动变成教堂。
